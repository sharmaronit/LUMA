# Luma debloat list: common to all Android TV / Google TV devices.
# Format: tier|package|description
#   safe        - ads, telemetry, demos, rarely used content apps (default run)
#   aggressive  - useful to some users; only removed with -Aggressive
#   launcher    - stock home screens; only removed with -DisableStockLauncher
#   never       - protected; the script refuses to touch these
# Packages that are not installed on the device are skipped automatically.
