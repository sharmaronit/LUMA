05 Install

Three ways in.
Pick yours.

Each one installs Luma, and each can switch off the bloatware that slows your TV down.

Easiest

On the TV only

  1. Install Downloader from the Play Store.
  2. Open it and enter github.com/sharmaronit/LUMA/releases/latest/download/luma.apk
  3. Install, open Luma and choose it as your Home app.
  4. Optional: Settings › Device › Clean my TV.
Works on every TV

With a computer

  1. Turn on USB debugging on the TV.
  2. Download luma.apk and run adb install luma.apk
  3. Run the cleaning script from the repo: scripts/debloat
Hands-off

With an AI assistant

  1. Turn on USB debugging on the TV.
  2. Open Claude Code, Codex or a similar assistant.
  3. Paste PROMPT.md and answer its questions.

Which download should I pick?

File sizes on the 1.0.1 release. The universal APK works on every TV; the smaller ones fit one processor type.
